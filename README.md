# NovaPeak Studio

A premium, responsive one-page digital agency site built for the Digital Heroes internship assessment.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Stack

React 19, Vite, Tailwind CSS v4, Framer Motion, and React Icons.

## Deployment

Import the repository in Vercel. It will detect Vite automatically; use `npm run build` and `dist` as the output directory. Set the production domain to `novapeak.studio` (or update canonical, Open Graph, robots, and sitemap URLs to match your domain).
